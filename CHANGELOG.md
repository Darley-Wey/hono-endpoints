# Changelog

## 1.0.0 - 2026-09-10

- First public release of Hono Endpoints for WebStorm 2026.2 and later.
- Discovers static Hono routes, including aliases, method chains, `basePath()`, and local `.route()` mounts.
- Provides source navigation plus the HTTP Client, OpenAPI, native JavaScript/TypeScript documentation, and client-examples Endpoints panels.
- Uses the native method-reference Quick Documentation target, preserving the editor's overload selection without custom HTML, handler parsing, or signature rewriting.
